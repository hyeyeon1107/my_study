1. Set은 리스트와 뭐가 달라요? 생각나는 대로 짧게 써 주세요.
내 대답 ->
Set은 말 그대로 잠시 거기에 둔 거? 라서 출력 순서가 다르게 나올 수 잇어 
 하지만 리스트는 확실히 이렇게 저장되어 있는 거라서 고정된 순서에 맞춰 출력해야만해
클로드가 다듬은 대답 ->
① Set은 순서가 없어서 출력 순서가 달라질 수 있고, 같은 값은 하나만 남는다. 
리스트는 넣은 순서가 고정이고 중복도 된다.

2. 문자열 슬라이싱 [시작:끝]은 손가락으로 어떻게 읽었어요?
내 대답
-> 시작 부분에 왼손을 놓고, 끝부분에 오른손을 두고 봐. 
    ex) 010-1234-5678
        [:3] -> 010 왼손은 0, 오른손이 - 에 가있어
        [9:] -> 5678 왼손이 -에 있고 오른손은 8에 있어
클로드가 다듬은 대답
-> ② 슬라이싱은 왼손(시작) 칸은 가져가고, 오른손(끝) 칸은 벽이라 안 가져간다.

3. 문자열 기능(replace, upper, split 등)은 결과를 상자에 담아요, 안 담아요? 왜요?
처음 대답
-> 문자열 기능 같은 경우는 상자에 담지 않아 아예 결과를 바꿔버리기 떄문이야 맞아?
피드백
-> 반대예요. 문자열 기능은 **상자에 담아요.**

헷갈릴 만해요. 리스트 기능(sort, append)이 "바꿔 버리는 쪽"이었거든요. 문자열은 그 반대예요.

| | 원본 | 상자 |
|---|---|---|
| 리스트 `sort()`, `append()` | 바뀜 (세탁기) | ❌ |
| 문자열 `replace()`, `upper()`, `split()` | **그대로** (복사본을 새로 써 줌) | ⭕ |

오늘 푼 문제에서도 그랬어요.

```python
short = msg.replace("아이스 ", "")
```

`msg`는 그대로였고, 새 문자열은 `short`에 담겼죠.

**다시 한 번**: 문자열 기능은 왜 상자에 담아야 할까요? 한 줄로 써 주세요.

다시 대답
-> 문자열 기능의 경우, 원본을 그대로 두고 복사본을 만들어 새로 써. 캡쳐 같은 거야. 그래서 새로 상자에 담아서 출력하게 되어 있어.
③ 문자열 기능은 원본을 그대로 두고 복사본을 새로 만든다. 캡처 같은 거라서 새로 상자에 담아서 출력한다.
