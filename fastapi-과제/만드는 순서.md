## model / db / schema 헷갈리지 않기

| 폴더 | 비유 | 예시 | 하는 일 |
|---|---|---|---|
| `models/` | 장부 양식 | `FileInfo` | DB 표가 어떻게 생겼는지 정의 |
| `db/` | 장부 담당 | `insert_file`, `get_files` | 양식을 써서 DB에 넣고 꺼내는 함수 |
| `schemas/` | 응답 모양 | `Fileschemas` | 밖(사용자)과 주고받는 데이터 모양 |

```
사용자  ⇄  routes  ⇄  db 함수  ⇄  DB
          └ schema ┘  └─ model ─┘
           (밖과 대화)   (DB와 대화)
```

- **model(`FileInfo`)**: DB와 대화할 때만 씀 → `db/` 함수 안에서만 보여야 함
- **schema(`Fileschemas`)**: 밖과 대화할 때 씀 → 요청 받을 때, 응답 보낼 때
- **`model_validate`**: model → schema로 바꿔주는 것 (경계에서 변환)

### 내가 헷갈렸던 장면 (전부 "밖과 대화하는 자리에 model을 씀")

- `-> FileInfo | None` → 밖으로 나가는 건 schema니까 `-> Fileschemas | None`
- `post_file(file: FileInfo)` → 사용자에게 받는 자리에 model을 씀 (파일은 `UploadFile`로 받음)
- `"FileInfo": result` → 응답 이름표에 model 이름 → `"file": result`

### 확인 요령

**`routes/` 파일에서 model 이름(`FileInfo`)이 보이면 뭔가 이상한 것!**
